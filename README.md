# The Game

https://github.com/user-attachments/assets/8163ab64-130f-479a-b22f-d57373155505

- The game is pretty simple. You have a player (white cube). There are four colored cylinders in the scene. And four gray capsules.

**Objectives:**

https://github.com/user-attachments/assets/cfc9bc34-e040-49e5-bdda-53062146e2aa

- Take a color from a cylinder...

https://github.com/user-attachments/assets/683fc15e-10ff-41a4-a7c8-55524aa784fc

and pass it to capsule. 

**For more thrill**

- There is a global timer. If you can color all four capsules - Victory screen and restart button. If not - Defeat screen and restart button.

https://github.com/user-attachments/assets/9d8ef14d-18b1-48df-8fe1-f92defdd0605

**For even more thrill**

- There are various traps.

https://github.com/user-attachments/assets/1cd1d970-4ea2-4284-a7f9-d2450abecfcc

If you collide with these traps - you will be send back to start position.
